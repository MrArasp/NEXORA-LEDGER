# NEXORA LEDGER

### نرم‌افزار حسابداری دسکتاپ برای مدیریت ساده و حرفه‌ای امور مالی

NEXORA LEDGER یک نرم‌افزار حسابداری دسکتاپ برای Windows است که با هدف ساده‌سازی مدیریت امور مالی، ثبت معاملات، مدیریت مشتریان و تأمین‌کنندگان، چک‌ها، اقساط، درآمدها و هزینه‌ها طراحی شده است.

این برنامه با رابط کاربری فارسی و راست‌به‌چپ طراحی شده و تلاش می‌کند امکانات موردنیاز یک سیستم حسابداری شخصی و فروشگاهی را در یک محیط ساده و کاربردی ارائه دهد.

# ⚠️ Windows Defender و SmartScreen

نسخه فعلی برنامه ممکن است به‌دلیل نداشتن **Code Signing Certificate** هنگام دانلود یا اجرای Installer توسط Windows Defender یا Windows SmartScreen با هشدار مواجه شود.

این هشدار می‌تواند به عواملی مانند unsigned بودن فایل، جدید بودن نرم‌افزار یا نبود سابقه اعتبارسنجی فایل در سیستم‌های امنیتی Windows مرتبط باشد.

### توصیه امنیتی

برای حفظ امنیت سیستم، **Windows Defender را به‌صورت کامل و دائمی غیرفعال نکنید.**

قبل از اجرای Installer:

1. فایل را فقط از منابع رسمی NEXORA دانلود کنید.
2. مطمئن شوید فایل از Release رسمی GitHub دریافت شده است.
3. نام فایل و منبع دانلود را بررسی کنید.
4. در صورت مشاهده هشدار امنیتی، جزئیات هشدار را بررسی کنید.
5. اگر درباره فایل یا منبع آن اطمینان ندارید، آن را اجرا نکنید.

> در نسخه‌های آینده، امکان ارائه نسخه‌های Code Signed برای کاهش هشدارهای امنیتی Windows در نظر گرفته خواهد شد.
